# Community Agent Skills

A curated collection of community-built AI agent skills for learning, experimentation, comparison, and adaptation.

## Purpose

This repository exists as a lightweight public catalog for useful skills and skill ecosystems created by the broader AI-agent community.

Its goals are to:

- preserve references to high-value community work;
- make interesting skills easier to discover later;
- support study and experimentation;
- document attribution and upstream provenance;
- provide a starting point for evaluating whether an idea should be adapted into a personal or project-specific skill ecosystem.

## What belongs here

Good candidates include skills or skill collections that are:

- reusable across projects;
- technically instructive;
- clearly scoped;
- well documented;
- useful as references for agent workflows, software engineering, product work, research, or automation.

This repository is not intended to claim authorship over third-party work.

## Relationship to Ariel Agent Skills

[`ariel-agent-skills`](https://github.com/oliveiraariel/ariel-agent-skills) is the maintained personal skill ecosystem.

The distinction is:

- **community-agent-skills** — references and community-originated material for study, comparison, and experimentation;
- **ariel-agent-skills** — selected, adapted, or original skills maintained as a coherent runtime-neutral engineering ecosystem.

Ideas discovered here may influence future adaptations, but they should not be copied into the maintained ecosystem without reviewing scope, attribution, licensing, overlap, and practical value.

## Attribution and licensing

Each referenced or forked project retains its original authorship.

Before redistributing, modifying, or incorporating third-party material, review the upstream repository's license and attribution requirements. The absence of an explicit license should not be interpreted as unrestricted permission.

## Curation principles

Prefer quality over quantity:

- keep provenance visible;
- avoid duplicate entries that teach the same mechanism;
- distinguish upstream material from local adaptations;
- document why a project or skill is worth keeping;
- preserve links to the original source whenever possible.

## Status

This collection is intentionally small and may evolve as new agent-skill ecosystems are evaluated.
